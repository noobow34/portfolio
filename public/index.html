HOBBY: ✈️ 飛行機

サイトを開く ↗ GitHub

日本の航空会社が保有する機材を、レジ（登録記号）単位で一覧・検索できるサイトです。 機体ごとの写真、稼働状況、更新履歴を公開し、しばらく飛んでいない機体を自動で検知して知らせます。 飛行機好きとして「この機体、今どうしてる？」を手軽に調べたくて作りました。

  • 航空会社グループ・航空会社・型式ごとの機材一覧と、機体ごとの詳細ページ
  • 運用状況や Wi-Fi 有無などでの条件検索。検索条件は名前を付けて保存・URL で共有
  • 稼働チェックの定期ジョブで「非稼働機」や稼働状況の変化を自動記録
  • 航空局の登録データ取込など、運営を回すための管理機能一式
  • X（@ja_fleet）と LINE Bot で更新情報を配信

HOBBY: 🩸 献血

献血の記録・計画管理サービス

サイトを開く ↗ GitHub

全国の献血ルームをスタンプ帳のように記録し、次の献血の計画まで管理できるサービスです。 献血には種類ごとの間隔や年間上限があって自分で数えるのが大変なので、それを自動でチェックする仕組みを作りました。 会員登録なし、専用 URL だけで使えます。

  • 全国の献血ルームをスタンプ帳形式で記録。ルームごとの献血履歴も確認できる
  • 予定・実績を管理し、献血インターバルと年間上限を自動チェック（採血した腕・機器・単位数も記録）
  • 閲覧専用 URL を発行してスタンプ帳を SNS でシェア
  • 献血ルーム公式ページとの差分を Gemini で定期チェックし、ルーム情報を最新に保つ
  • 関連ツール：献血ルームの予約空きを横断検索する Windows アプリ KenketsuAvailability
